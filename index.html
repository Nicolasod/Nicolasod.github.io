01. Sobre mim

Sou engenheiro de IA, com foco em IA aplicada, agentes e automação. Por iniciativa própria, criei um ecossistema multiagente — 1 orquestrador e 6 agentes especialistas, com Claude API e Claude Code — que apoia minha rotina de trabalho: triagem, rascunhos de resposta, geração de fórmulas e relatórios e consulta a uma base de conhecimento própria.

Também construo agentes de WhatsApp com n8n, Claude API e pgvector, e aplicativos mobile em React Native. Minha base vem de Python, JavaScript/Node.js, Java e SQL em ambientes corporativos.

Gosto de soluções diretas e seguras: toda ação de um agente em sistema real passa por aprovação humana.

03. Projetos

Sistema Multiagente de IA

Ecossistema com 1 orquestrador e 6 agentes especialistas (Claude API e Claude Code) que faz triagem de demandas, gera rascunhos de resposta, fórmulas e relatórios e consulta uma base de conhecimento própria em Markdown. Toda ação em sistema real exige aprovação humana explícita, com logs e kill-switch. Projeto pessoal, código privado.

Claude API Claude Code Agentes Orquestração Human-in-the-loop

Agente de WhatsApp com IA

Agente de atendimento e qualificação de leads para imobiliárias via WhatsApp Business API. Fluxo em n8n, Claude API com lógica de qualificação e memória/busca semântica em Supabase com pgvector.

n8n Claude API Supabase pgvector WhatsApp API

Geradores de Código com IA

Ferramentas que usam Claude para gerar scripts e fórmulas a partir de uma descrição, apoiadas por uma base de conhecimento de exemplos reais, geração em streaming (FastAPI) e fluxo de aprovação antes do uso.

Claude API FastAPI Streaming Base de conhecimento
